# Argo-AntiVirus
Argo Antivirus: scanner di file per Android. Controlla se un file è sicuro con un database di malware noti (ClamAV) e, se vuoi, con VirusTotal. Descrizione più lunga (per il file README o per presentarlo): Argo Antivirus è un progetto personale che analizza i file del telefono e dice se sono sicuri, sospetti o pericolosi.
